Overview
This project is a course-selling platform that provides functionalities for administrators to manage courses and for learners to view and explore available courses. It demonstrates the implementation of a user-friendly interface, robust user authentication, and role-based access control.

Features
User Authentication
Sign Up/Login System: Users can sign up and log in securely using Firebase Authentication.
Session Management: Sessions are handled to keep users logged in while navigating the platform.
Welcome Email: Upon account creation, a welcome email is sent using SendGrid.

Role-Based Access Control
Admin Role:
Add new courses with details such as title, description, and price.
Update or delete existing courses.
Manage the course list efficiently.

Learner Role:
View all available courses.
Enroll available courses.
Explore course details.

Course Management
Dynamic course management allows real-time updates for admins.
Learners get an optimized and responsive interface to browse courses.

Technology Stack
Frontend:
HTML/CSS: Used for creating the user interface.
JavaScript: Enables interactivity and dynamic elements.

Backend:
Framework: Node.js
Database: Firebase Firestore for storing user and course data.
Authentication: Implemented using Firebase Authentication.

Email Notifications: SendGrid is used to send welcome emails.

Deployment:
Deployed and hosted using Vercel.
